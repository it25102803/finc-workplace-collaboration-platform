# Finc Workplace Collaboration Platform

**Course:** SE2012 - Object Oriented Analysis and Design  
**Client:** Finc Academy and Consultants (Pvt) Ltd  
**Framework:** Java Spring Boot (Spring Web / MVC)  

---

## 📌 Project Overview
Finc Workplace Collaboration Platform is a cloud-based internal collaboration solution designed to centralize team messaging, role management, project tracking, and document knowledge management for Finc Academy and Consultants (Pvt) Ltd.
